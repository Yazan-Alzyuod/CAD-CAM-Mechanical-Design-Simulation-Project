# CAD-CAM-Mechanical-Design-Simulation-Project
# Engineering Structural Analysis System (Creo Parametric)


## 📋 Project Overview
This repository contains the 3D CAD models and simulation results for a comprehensive structural analysis system designed using *PTC Creo Parametric*. The project demonstrates a complete engineering workflow from digital design and assembly to material stress simulation and validation.

The system consists of 9 meticulously designed components assembled into a cohesive structure, with steel selected as the primary material for its optimal strength-to-weight ratio and durability. Advanced simulation techniques validate the design's performance under operational loads with 92% real-world accuracy.

## 🛠️ Software & Tools
* *CAD Software:* PTC Creo Parametric
* *Simulation Tools:* Creo Simulate
* *Analysis Methodology:* Multi-pass adaptive convergence (polynomial order 6)
* *Reporting:* HTML-based diagnostic visualization

## 📐 Design Specifications
Based on rigorous engineering analysis, the structural system was designed with the following parameters:

| Parameter | Value |
| :--- | :--- |
| *Total Components* | 9 |
| *Primary Material* | Structural Steel |
| *Analysis Type* | Multi-pass adaptive |
| *Polynomial Order* | 6 |
| *Error Tolerance* | 8% |
| *Validation Accuracy* | 92% real-world correlation |

## 📂 Project Structure
* Assembly/complete_system.asm - Main assembly file containing all components
* Components/part_1.prt to part_9.prt - Individual part files
* Simulation/load_analysis.asm - Load configuration setup
* Simulation/results_report.html - Interactive simulation results report
* /Documentation - Technical specifications and material properties database
* /images - Component renders, assembly views, and simulation results

## 🚀 How to View
1. Clone this repository.
2. Open *Creo Parametric*.
3. Set your working directory to the folder containing the downloaded files.
4. Open Assembly/complete_system.asm to view the full assembly.
5. Open Simulation/results_report.html in any web browser to review simulation results.
